Authentication

Every request needs an API key. Send it in either of these ways.

MethodExample
HeaderX-Api-Key: YOUR_API_KEY
Query parameter?key=YOUR_API_KEY

Create and manage keys in your what3words account, or compare API plans.

Errors

Errors return an HTTP status and a JSON body with a stable code and a readable message. Branch on code, and handle codes you do not recognise.

StatusMeaning
400A parameter is missing or invalid
401The API key is missing, invalid or lacks permission
402The feature is not on your plan, or your quota is used up
